# Портфолио Алана Хубежова

Современное портфолио frontend-разработчика, построенное на Next.js, TypeScript, Tailwind CSS и Three.js.

## Особенности

- 🌗 Тёмная тема по умолчанию
- 🌐 Поддержка русского и английского языков
- ✨ Анимации с Framer Motion
- 🎨 3D-фон из частиц
- 📱 Полностью адаптивный дизайн
- 📧 Форма обратной связи через EmailJS
- 🔍 SEO-оптимизация (sitemap, метатеги)
- 🚀 Деплой на GitHub Pages

## Локальный запуск

```bash
npm install
npm run dev
